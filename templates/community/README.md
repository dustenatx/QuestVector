# Community mission templates

Contributed `.qv-mission.yaml` templates go in this folder. See
[CONTRIBUTING_TEMPLATES.md](../../CONTRIBUTING_TEMPLATES.md) for the schema and
submission steps, and start from [`../boilerplate.qv-mission.yaml`](../boilerplate.qv-mission.yaml).

The seven built-in starter templates ship inside the package
(`questvector/data/starter_templates/`); `qv launch` copies them into each
workspace's `templates/starter/` folder.
